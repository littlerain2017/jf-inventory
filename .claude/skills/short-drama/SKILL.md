# 爆款剧本工坊 (Drama Workshop) - 概览

这是一个专业微短剧创作系统，支持国内和出海双模式。核心流程为：

**创作路径：**
选题 (`/开始`) → 策划 (`/策划`) → 角色开发 (`/角色开发`) → 分集目录 (`/分集目录`) → 逐集写作 (`/分集`) → 质检 (`/自检`) → 诊断 (`/圆桌诊断`) → 导出 (`/导出`)

**关键特性：**
- **跨集追踪**：连续性台账自动管理身份、信息、承诺的传递
- **三层质控**：地基层(100%) | 骨架层(75%) | 血肉层(35%)，分级阻断
- **承制分化**：支持仿真人AI剧(`ai_live`)和漫剧(`comic`)，介质限制不同
- **出海规则**：独立合规、文化禁区、付费墙模型
- **工作目录**：统一存储于 `~/short-drama-projects/`，无需切换目录

**实战工具：**
- `/选题会`：3位专家碰撞选题方向(5分钟)
- `/圆桌诊断`：质检不达标时的修改处方生成
- `/角色一致性`：跨集人物检测
- `/分镜`：将剧本拆解为AI可用的镜头表

所有文件操作遵循 Read-Modify-Write 协议，禁止破坏式覆盖。
